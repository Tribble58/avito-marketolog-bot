# AVITO Marketolog Bot

## Description
This product serves as a useful helper for marketologs that work with clients in Avito marketplace. It provides functionality regarding:  
- chat interaction (reading messages, replying, creation of template messages)
- accounts managing (connection, disconnection of accounts)
- notifications (subscription to notifications) 
- and so on
## Stack
**Backend**: aiogram, requests, FastAPI \
**Database**: PostgreSQL 14.2
